# Brand Style Notes

## Direction

Papercut should feel like Paper OS: crisp, document-native, tactical, and human.
It should borrow from cut paper, stamped status, packet tabs, poster proof, and
operational receipts without becoming messy or generic.

## Personality

- bold
- intelligent
- strategic
- warm
- grounded
- proof-oriented
- serious enough for civic and admin work
- visually memorable enough to avoid generic SaaS sameness

## Visual Ingredients

- black ink
- warm paper
- red action stamps
- blue proof marks
- green ready marks
- document rails
- packet tabs
- workflow arrows
- receipt lines
- Xerox/cutout poster texture used sparingly

## Avoid

- generic SaaS gradients
- vague automation magic
- private-data screenshots
- school-specific public language
- fake provider claims
- public copy that implies live dispatch without gates
