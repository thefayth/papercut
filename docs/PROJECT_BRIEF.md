# Project Brief

## Name

Papercut

## One-Line Description

Papercut is a review-first paperwork operations system for packets, portals,
email, fax, signatures, memory, and dispatch receipts.

## Purpose

Papercut helps recurring paperwork work become trackable, reviewable, and
repeatable. It gives an operator a private command center for documents,
deadlines, signatures, portals, packets, provider readiness, and follow-up
history while preserving human approval before irreversible actions.

## Product Thesis

Most paperwork failures are coordination failures. Papercut turns the
coordination layer into software: queue the work, preserve originals, prepare
review copies, rehearse portal flows, check provider readiness, and write down
what happened.

## Public Promise

Papercut can publicly explain the workflow model, safety posture, and product
direction without publishing the private engine.

## Private Engine

The private engine includes the application source, authenticated workspace,
data indexes, worker runs, vault entries, provider configuration, packet
artifacts, and customer or personal records.
