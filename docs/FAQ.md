# FAQ

## Is Papercut open source?

No. This repository is a protected public project surface. It is not a source
release and does not grant a public license.

## What is public here?

Product description, workflow diagrams, brand notes, public-safe images,
status, roadmap, ownership terms, and WordPress draft copy.

## What stays private?

The application source, prompts, credentials, provider configuration, uploaded
documents, signatures, faxes, packets, screenshots, private workflow records,
customer data, deployment systems, and operational infrastructure.

## Can public demos send real email or fax?

No. Public demos are fake and non-sending.

## When can real dispatch happen?

Only inside authenticated private routes, only when the matching provider is
configured, only when review-only mode allows it, and only after per-item
approval.

## Why GitHub if the source is private?

GitHub can still be a professional project surface: a place for public product
story, diligence materials, ownership notices, docs, diagrams, and links back
to FaithCheltenham.com.

## Who owns Papercut?

agreement.
