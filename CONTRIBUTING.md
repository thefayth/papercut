# Contributing

Papercut is not accepting public source-code contributions through this
protected surface.

This repository is documentation-first and proprietary. Public feedback is
welcome when it helps clarify:

- product positioning
- accessibility
- public/private boundaries
- safety language
- documentation accuracy
- partner-readiness materials

Do not submit:

- private documents
- personal records
- credentials
- operational screenshots
- customer data
- school, benefits, medical, legal/admin, or family records
- source-code patches that assume an open-source license

Commercial partnership, licensing, or implementation discussions should route
through FaithCheltenham.com.
